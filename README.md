## Featured Projects 🔬

**🩺 [ner-clinic-es](https://github.com/38diego/ner-clinic-es): clinical NLP in Spanish** · [live demo](https://ner-clinic-es-355389257185.us-central1.run.app)<br>
It reads a clinical note in Spanish and finds the diseases of the patient. It says if each one is confirmed, denied, suspected or from a family member, and it calculates the Charlson index and suggests an ICD-10 code. Evaluated with public corpora (F1 0.88 to find diseases), with an API, a web demo on Google Cloud Run and automatic deployment.

**🏥 Undergraduate thesis: morbidity profile and clinical data quality** · [case study](https://github.com/38diego/ner-clinic-es/blob/main/docs/caso-de-estudio.md)<br>
With my team, we built a data architecture and an NLP pipeline for the hospital discharges of a hospital in Bogotá. We processed **42,983 discharges** and found that **84.9 % of the patients had at least one comorbidity that was only in the free text**, without a code in the records.
